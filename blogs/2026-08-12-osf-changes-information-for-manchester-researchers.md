The Center for Open Science (COS) has announced changes to OSF (Open Science Framework), which will affect how researchers use the platform for project management, collaboration, file storage, and sharing. OSF has been a valuable tool for many researchers at The University of Manchester, supporting preregistration, collaboration, and transparent research workflows. While some core features will continue, the changes mean that researchers currently using OSF as an active project workspace will need to review their workflows and consider alternative solutions for some activities.
